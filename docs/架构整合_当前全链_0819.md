## 0. 一页总览

```
┌──────────────────────── 离线建图带（每场景一次性，GPU服务器） ────────────────────────┐
│ ZED采集(posed RGB-D) → COLMAP/VGGT位姿 → 3DGS重建(深度监督) → align世界对齐          │
│   → untwist/zlevel扶平 → 场景图ConceptGraphs(185节点) → 三角化精化+LSD front         │
│   → targets json (站名→坐标/front/锚定窗)                                            │
└──────────────────────────────────────────────────────────────────────────────────┘
                                    ↓ 产物: world ply / sim_world npz / targets json
┌──────────────────────── 在线任务带（lab_mission.py 单进程闭环） ─────────────────────┐
│                                                                                    │
│  慢脑(异步HTTP)  VLM四段链confirm + key-frame复核 │ RAG检索→站点τ                     │
│        │                                           │                                │
│        └──────────→ NavCmd{L, τ, Φ=(W,γ,vx)} ←─────┘                                │
│                          ↓ 注入                                                     │
│  FPV渲染(gsplat真内参) ─┐                                                           │
│  BEV占据窗+时序历史W/γ ─┼→ DiffusionDrive快脑(scene_gate) → 8×3多模轨迹Top-1        │
│  status(goal,head,vx,W,γ,mode) ─┘        ↓                                          │
│                     控制器turn-then-go + safe_vel间隙场 → (vx,vy,wz)                │
│                          ↓                                                          │
│  RELOC精定位: 回归头3ms → 闸门1步长 → 闸门2渲染验证loss → GS渲染优化43s兜底          │
│                          ↓ believed位姿                                             │
│  到站链: ALIGN(front对准,EDGE>2°回滚) → confirm+复核 → DOCK(min(ED,几何)贴脸)       │
│          → UNDOCK → 下一腿                                                          │
└──────────────────────────────────────────────────────────────────────────────────┘
```

**一句话**：场景图RAG慢脑产出结构化参数包 NavCmd 注入 DiffusionDrive 快脑做轨迹生成；RELOC 子系统（回归头+GS渲染优化）负责厘米级位姿纠偏；到站后由 ALIGN→confirm→DOCK 链完成贴脸对接。仿真与真机共用同一套 (vx,vy,wz) 接口。

## 2. 在线双脑：慢脑 → NavCmd → 快脑

### 2.1 快脑 DiffusionDrive

- 基座：`arch_e2e/weights/best-val-loss.ckpt`（NAVSIM 预训）+ resnet34 + `kmeans_navsim_traj_20.npy`（20锚点扩散先验）。
- 微调 ckpt（只换 trajectory_head+status_encoding）：
  - `goalnav/runs/goalnav_gate.pt` —— **走廊版**
  - `goalnav_gate_lab.pt` —— 实验室默认
  - `goalnav_gate_lab_v4/v5.pt` —— v4=时序历史条件(hist_w)，v5=mode=1搜索行为（骨架化DFS数据856样本）
  - lab_mission 用 `CKPT` env 选择
- 输入（`lab_mission.py:284 dd_traj`）：
  - `camera_feature`：FPV渲染（gsplat，真实采集内参，`scripts/capture_fpv.py`）
  - `lidar_feature`：局部BEV占据窗（点云=`gs_vggto_{session}_world.ply`）；**hist_w>0 时走时序历史**：位姿环形缓冲 W 窗、点级 γ^lag 衰减融合（官方直方图/架构零改动，W=0 与旧版逐位一致）
  - `status_feature` 8维：`[goal_ego, head_ego, vx, hist_w/8, gamma, mode]`
- 输出：8×3 轨迹 → turn-then-go 控制器（大角度DD转、小角度控制器收尾）→ safe_vel 间隙场安全层（`lab_mission.py:250`）→ (vx,vy,wz)
- scene_gate 机制：零初始化场景门，转向时 g→0.046 关场景前向推力（0714 落地，门正则 gate_reg=0.3+固定种子锁定）
- 训练数据：`gen_nav_dataset_lab_v3/v4/v5.py` → `outputs/nav_ds_*_v{3,4,5}/`；训练 `goalnav/pipeline/train_goalnav_gate_v*.py`

### 2.2 慢脑 VLM（异步 HTTP，不阻塞2Hz节拍）

- 接口：`arch_e2e/pipeline/sim_fullchain.py:75 vlm_api()`，`VLM_URL` env 切换：
  - 自研 Infinite VLM = `http://10.0.0.18:8152/api/generate`（默认，0.42-0.53s/次）
  - 本地对照 Qwen3.5-4B = `http://127.0.0.1:8152`（`scripts/vlm_server_local.py`，artifixer env，GPU3常驻，关enable_thinking）
- 调用点：
  - **confirm**（`lab_mission.py:1293`）：**四段推理链** History/Scene/Progress/Action 分段独立落盘 → `outputs/lab_mission_slowbrain_0803.jsonl`；判 NO 时 **key-frame 复核**（接近过程 top3 证据帧，≥2帧 yes 才翻案）
  - 巡检经理（`run_inspection.py`）：go_straight/veer_left/veer_right 三选一
- RAG检索：`cg_rag_query.py` / `cg_rag_vlm_rerank.py`，文本→场景图节点τ
- 铁律：**VLM 口头方位是垃圾，只信 bbox/几何**；confirm 用真图不用渲染图（渲染溅射会掷硬币）

### 2.3 NavCmd 参数包（慢脑→快脑契约）

`lab_mission.py:110-131`：每腿派发 `NavCmd{L, τ, Φ}` 并落盘。Φ 映射：CRUISE(W2, γ0.7, vx0.5) / STRAFE / ALIGN(W8, γ0.85, vx0)。goal=0 即搜索开关（mode位冗余教训，0803）。

## 3. RELOC 精定位子系统（0811-0813 落地）

两条路 + 双闸门 + 兜底（`lab_mission.py:344 reloc_correct`）：

```
believed位姿 + zed观测
   │
   ├─ 快路: 回归头 (outputs/reloc_head_0812/reloc_head.pt, v4双域42.7k样本)
   │    CNN 2ch(深度90x160+mask)+pose4 → Δ(dx,dy,dyaw), <10ms
   │    闸门1: |Δ|>1m/40° 拒收
   │    闸门2: 纠正位姿单帧320x180渲染验证 Charbonnier loss>0.08 拒收
   │
   └─ 兜底: GS渲染优化 (scripts/gs_relocate.py GSReloc)
        zed度量深度×OBS_SCALE=0.70 vs gsplat渲染ED
        coarse-to-fine Adam+Charbonnier+IRLS, ~43s/次
        真zed 24帧评测: 收敛域±0.5m/±25°, 水平中位5.6cm(p90 8.9), yaw1.08°
        终loss>0.08 拒收
```

- 调用时机：①到站纠偏（`--reloc_demo`）②巡航周期纠偏（`--reloc_odom`，每~2m `odom_checkpoint`，smooth slew 渐进施加）
- 已知残留：回归头 sim 闸门 accept 仅 2/9（真值兜底正确）；真zed val帧 15.3cm/4.5°（训练帧1cm有记忆成分）
- 真机形态已备好：`reloc_server.py`（GPU常驻，POST /reloc，内部自动0.70×换算）+ `reloc_client.py`（Orin端仅 numpy+requests）

## 4. 到站后段链：ALIGN → confirm → DOCK → UNDOCK

| 阶段 | 位置 | 机制 | 精度（0813三修后真值复核） |
|---|---|---|---|
| ALIGN front对准 | `lab_mission.py:870` | 地图front转向+横移上轴闭环至 \|bearing-front\|<1.5°；EDGE线伺服（LSD近水平线）与地图front偏差>2°时**回滚地图front**（防白桌锁错线污染） | 柜0.74°/微0.04°/桌0.70° |
| confirm | `:1293` | 真图VLM四段链 + key-frame复核 | 白桌溅射区仍偶发掷硬币（残留） |
| DOCK 贴脸对接 | `:1139` | **min(渲染ED, 几何dist-FACE_OFF) 双源测距**伺服（防ED近距过读玻璃10-25cm）+ 缝/簇锚定窗居中 + 盲爬15cm | 三站15cm面距，横向≤0.7cm，柜+0.4cm |
| UNDOCK | `:1276` | 盲退+转向撤离 | — |

**0813 教训（写进代码注释）**：对接/对准指标必须 trace 真位姿复核，believed 指标会自欺（缝锁错、EDGE带偏yaw、front自比同义反复都是 trace 复核锤出来的）。

## 5. 任务编排：lab_mission.py

主脚本 `scripts/lab_mission.py`（1560行，入口 `main():61`）。

- **运行铁律**：`CUDA_VISIBLE_DEVICES=3 MUJOCO_GL=egl PYOPENGL_PLATFORM=egl ~/discoverse_venv/bin/python scripts/lab_mission.py ...`（必须 discoverse_venv，系统python缺glfw）
- 腿定义（:196-201）：原位 →A*→ 铁柜 →STRAFE→ 显微镜 →A*→ 移液枪白桌 →A*→ 回原位
- 状态机：CRUISE/STRAFE → TURN/FACE → RELOC → ALIGN → confirm → PRECISE-DOCK → UNDOCK → WAIT → 下一腿；另有 SEARCH demo（`--search_demo N`）
- 关键CLI：`--session`、`--targets`（**必须带 zed_front_perp_lvl.json**，默认 zed.json 无 front_deg 会退化成1.66m远站位）、`--hist_w_cruise 2 --hist_w_align 8`、`--reloc_odom`、`--reloc_head`、`--pitch_cruise -22 --pitch_station -12`、`--precise_dock`、`--flow`、`--sb_log`
- 走廊变体：同脚本换 session/targets/CKPT=goalnav_gate.pt 即走廊4泵站任务
- 旧线角色：`run_inspection.py`（7月走廊巡检状态机）与 `sim_fullchain.py`（全链demo+被import的库）已被 lab_mission 吸收，维护重心在 lab_mission

## 7. 已知残留（诚实清单）

1. **世界尺度0.70×未根治**：在线 OBS_SCALE 兜底，新场景建图必须用正确 cam_height。
2. **回归头双域代价**：真zed val帧15.3cm（v3单域12-14cm），sim闸门accept率2/9；闸门逻辑本身已验证可靠（loss不下降的溅射区假接收已修）。
3. **白桌confirm渲染溅射**：VLM用真图，溅射区几何量（loss地形）不可信。
4. **走廊任务返程崩溃（08-13晚）**：`odom_checkpoint→reloc_correct` R1 NoneType（lab_mission.py:444），:437 已加观测不足守卫但崩溃在守卫后路径，**待复核修复**。
5. **±45°原地转为OOD**（训练只覆盖±90°），控制器夹角处理。
6. GPU2-7常被外部任务（starVLA）占满，训练/挂机要挑卡。
