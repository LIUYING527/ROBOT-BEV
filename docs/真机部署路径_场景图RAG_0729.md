# 场景图 RAG 真机部署路径研究（0729 深夜）

> 触发问题："之前用的不就是 VLM 看真图吗？" —— 对。本文把"场景图 RAG + 视觉伺服 + 指定路径任务"
> 从仿真搬到真机新场景的完整路径想清楚：什么变简单、什么是真风险、零样本问题怎么重新表述。

## 0. 核心澄清：VLM 的病是仿真特有的

- 自研 VLM 的全部已验证能力（yes/no 确认、bbox 定位、多帧 ANY 检测、比 Qwen 快 4.3×）都是在**真实采集帧**上测的（走廊 nav_ds_real、实验室 SRC 帧）。
- 仿真里伺服/bbox 不稳，唯一原因是 **3DGS 皮肤 off-path 渲染糊**（0626 已定论=采集物理天花板）。
- **真机上 VLM 看的是实时真图 = 它最稳的工作区。仿真里折腾的三轮伺服补丁，在真机上大概率一轮就收敛。**

## 1. 真机新场景部署全流程（三阶段）

```
阶段0 巡逻建图采集(每场景一次): 机器人遥操作/自动覆盖走一圈,
       录 ZED RGB-D + 轮式里程计+IMU+SLAM 位姿 (数据基础=我们已有的采集栈, 110744 就是这格式)
          │
阶段1 建图(离线, 服务器/工控机): 逐帧RAM+DINO+SAM检测 → cfslam增量融合 → 场景图
       成本: 510帧stride5≈100帧×4.25s≈7分钟(A100); stride2≈20分钟
          │
阶段2 任务期(任意多次): "去X" → 场景图检索(毫秒) → 节点坐标+最佳观测位姿
       → A*/快脑导航 → 到场视觉伺服(真图bbox) → 确认执行
```

### 关键：坐标系比仿真管线更干净
- 仿真里我们要绕 COLMAP 是因为**采集数据没有机器人里程计**（110744 是手持/外部采集）。
- 真机上**巡逻和任务用同一个 SLAM 会话/地图**：场景图节点坐标原生就在机器人自己的地图系里，导航直接用，零对齐、零外参标定。这是真机反而更简单的地方。

## 2. 组件对价表（仿真 → 真机）

| 组件 | 仿真里的角色 | 真机上 | 变化 |
|---|---|---|---|
| 自研 VLM | 看渲染图（糊→不稳） | 看真图（已验证稳） | **变可靠** |
| 场景图几何 | COLMAP 离线精修位姿 | 机器人 SLAM 在线位姿 | ⚠️ **真风险**：在线 SLAM 漂移→节点坐标偏差。缓解：带回环的 SLAM，或巡逻 bag 离线建图（仍"巡逻一次"） |
| 3DGS 皮肤 | 渲染 FPV 喂 VLM/快脑 | **不需要了**（真相机） | 整个砍掉 |
| BEV 占据 | 皮肤同源几何出 | 实时点云 BEV（团队 DiffusionDrive 车上就是这么喂的，接口已对齐） | 平移 |
| 快脑 DiffusionDrive | sim 里跑 | 车上已部署（4 模式版） | 平移 |
| A*/伺服/状态机 | 已验证 | 同构 | 平移 |

## 3. "新场景能直接用吗" —— 重新表述

不是"零样本直接用"，是 **"巡逻一次，长期复用"**：

- 工业巡检的真实使用模式就是站点制：一个厂房建一次图，之后跑几个月任务。~10-20 分钟的一次性建图成本是可接受的（语义建图领域标准做法，不是我们的缺陷）。
- 有速度/质量旋钮：稀疏巡逻（stride 10, ~50 帧, 检测 3 分钟）出粗图 vs 密集巡逻出精图。
- 真要"完全零建图"的兜底，就是老的在线 locate_target（VLM bbox+深度反投影）——已实测单扫弱，只配当 fallback 不配当主力。

## 4. 对论文叙事的影响

- 卖点本来就是"语义可控多模态轨迹分布"+真机护城河，场景图是基础设施不是卖点 → 建图成本不伤 novelty。
- 反而多一个故事点：**场景图把感知 front-load 成资产，任务期退化为毫秒检索+真图确认**；节点还免费携带"最佳观测位姿"（哪里看得最清楚），这是纯几何定位给不了的。

## 5. 建议验证顺序

1. **仿真里模拟真机时序演一遍全流程**：把 110744s2 的 510 帧假装成"巡逻采集"，在线时序喂给建图（stride 5），然后做任务 —— 验证"巡逻→建图→任务"的时序闭环和精度随 stride 的衰减曲线（这个现在就能做，零成本）。
2. **真机小场景首验**：一个房间，巡逻建图，跑"去显微镜"单目标任务 —— 重点测 SLAM 位姿漂移对节点精度的影响（对照 tape measure）。
3. 然后才是完整三站任务上真机。

## 6. 实测：巡逻密度衰减（0729 深夜，全链三层检索）

| 巡逻密度 | 节点数 | 显微镜 | 铁柜 | 白桌 | 结论 |
|---|---|---|---|---|---|
| s2（255帧，~10分钟巡逻） | 185 | 0.50m | 0.55m | 0.60m | ✅ 可靠 |
| s5（102帧，~3-4分钟） | 46 | 1.18m | 0.69m | 0.88m | 🟡 可用+VLM到场兜底 |
| s10（51帧） | 9 | 不可靠 | 1.6m | 5.15m | ❌ 不可行 |

要点：几何覆盖三密度全≤0.34m（鲁棒）；语义特异性先死（s5/s10 无"microscope"标签票）；
VLM 精排在 s5 能救援（显微镜 2.57→1.18m，铁柜级联修复 2.97→0.69m），
s10 节点太糙出现 VLM 假阴性（真显微镜判 no）救不回——**建图密度是硬下限，真机按兴趣区采密设计**。
