## §1 我们的系统：一张分层全景图

整个项目 = **一个机器人导航全栈**，自下而上五层。每层记三个东西：干什么、入口文件、产物。

```
┌─ ⑤ 任务闭环（大脑指挥身体）──────────────────────────────
│  lab_mission.py (主入口, 1560行)
│  慢脑(场景图RAG找目标坐标+VLM四段confirm) → NavCmd(L,τ,Φ)
│  → 快脑DiffusionDrive出8点轨迹 → 全向控制器(vx,vy,wz)
│  状态机: CRUISE→[RELOC纠偏]→ALIGN→confirm→DOCK→UNDOCK
├─ ④ 定位（不迷路的关键）──────────────────────────────────
│  RELOC: 回归头(<10ms, 双闸门) → 不行则GS渲染优化(43s)兜底
│  gs_relocate.py / reloc_server.py(GPU常驻) / reloc_client.py(Orin)
│  实测: 真zed水平5.6cm/yaw1.08°, 收敛域±0.5m/±25°
├─ ③ 快脑（小脑，扩散策略）────────────────────────────────
│  DiffusionDrive迁移到机器人: 输入{RGB, BEV占据, status8维}
│  status = [goal_xy, cos/sin朝向, vx, W/8, γ, mode]
│  训练链: train_goalnav.py→turn→gate→v2→v3(W/γ时序)→v4(mode搜索)
│  ckpt库: goalnav/runs/*.pt (最新 lab_v5 / r2r_dense训练中)
├─ ② 建图（离线，一次性）──────────────────────────────────
│  auto_map_pipeline.sh (0901新): zed采集→COLMAP位姿→3DGS
│  →世界对齐(cam_height尺度锚)→占据栅格occ_bev→nav_ds
│  产物: gs_vggto_<s>_world.ply + sim_world_<s>.npz + occ_bev
├─ ① 评测与对标（证明我们行）──────────────────────────────
│  R2R链: gen_dense_data→train_goalnav_r2r_dense→our_server
│        →run_r2r.py→probe_oracle_goal.py(瓶颈探针)
│  LH-VLN链: our_eval/run_our_eval.py (官方metrics复算)
│  baseline: DualVLN官方代码+我们写的cfg/客户端
└─────────────────────────────────────────────────────────
```

**三条主线记住就能讲清整个项目**：
1. **双脑** = 慢脑（VLM/场景图，决定"去哪"WHERE）+ 快脑（扩散策略，决定"怎么走"HOW）。
2. **RELOC** = 无里程计环境下的周期纠偏（每~2m把漂移拉回真值），是 cm 级精度的来源。
3. **语义可控** = 同一个目标，换语义条件（巡航/检视/搜索），轨迹分布明显不同——别人没有的机制（scene_gate 门值 0.98→0.046 是铁证）。

## §2 导航领域概念地图（用我们的系统讲术语）

### 2.1 任务谱系（导航问题从易到难）
| 任务 | 定义 | 谁在做 | 我们的关系 |
|---|---|---|---|
| PointNav | 给坐标走到点 | 已解决(99+%) | 我们 A*+快脑覆盖 |
| ObjectNav | 找"椅子"这类物体 | VLFM/GOAT | LH-VLN 的子任务形态 |
| **VLN** | 按自然语言指令走（"穿过客厅到卧室门口停下"） | **主战场** R2R/RxR | R2R 链正在追 |
| **LH-VLN** | 长程多阶段 VLN（2-4个子任务串） | FantasyVLN/DualVLN | **我们已超 DualVLN 的主场** |
| 巡检/对接 | 到设备面前 cm 级对准 | 工业界，学术少 | **我们的独门** |

### 2.2 核心术语（每个都指到我们代码）
- **BEV（鸟瞰图）**：把传感器点云压成俯视 2D 直方图，当模型的"地图输入"。DiffusionDrive 原版吃 360°LiDAR ±32m；我们只有 ZED 前向锥→裁 FOV110° 版本（`stage_b_eval.py: lidar_feature_fov`）。
- **扩散策略（Diffusion Policy）**：不直接回归轨迹，而是学"从噪声逐步去噪出轨迹"。好处=**多模态**（同一个观测能采出多条不同合理轨迹），回归会 mode-averaging（两条路平均成撞墙）。我们的快脑 = DiffusionDrive（自动驾驶 NAVSIM 的 SOTA 扩散轨迹模型）迁移到室内机器人。
- **模仿学习 IL vs 强化学习 RL**：我们全走 IL（专家轨迹监督，teleport 回放造数据 `gen_dense_data.py`）；RL 后训练（X-NavDP 真机 10→65%）是排队项。
- **快慢脑（Dual-System）**：慢脑 VLM 秒级语义决策，快脑小模型 10-30Hz 反应。**注意：这个通用架构不是创新点（DualVLN 已发），我们的创新在快脑的条件机制**。
- **重定位（Relocalization）**：知道自己在地图哪。渲染对比法（render-and-compare）= 在地图上渲出"如果我在这会看到什么"，和真实观测比，梯度优化位姿。我们 RELOC 就是 3DGS 版 render-and-compare + 回归头加速。
- **收敛域**：render-and-compare 只在初始位姿附近小范围（我们实测 ±0.5m/±25°）能收敛，外面会发散到垃圾解——所以必须**周期触发**（漂移还没出收敛域就纠）+ **双闸门**（纠正结果不靠谱就拒收）。iComMa/iGaussian 两篇独立论文的大扰动失败实验是这个设计的学术背书。
- **sim-to-real（仿真到真机迁移）**：仿真训模型直接上真机。我们的版本更特别：**仿真器本身就是用真机采集重建的**（ZED→COLMAP→3DGS→DISCOVERSE），域差天然小。
- **oracle / GT 泄漏**：oracle=给模型作弊信息（真值路径）用来诊断上限。`probe_oracle_goal.py` 就是"喂真值目标点看快脑能跑多好"——它把"慢脑不行"和"快脑不行"分开，0831 靠它实锤快脑"永远直走"病。
- **teleport 回放**：造训练数据的手法——不让 agent 真走，直接把相机瞬移到参考路径上渲观测（`gen_dense_data.py`），便宜量大。
- **stop 问题**：VLN 里"到了要停下来"看着简单实际是主瓶颈之一（DualVLN 用末帧×5上采样监督；我们试过 stop 头/轨迹幅度，发现逐步独立判停有不可约假射率）。
- **实例接地（grounding）**：指令说"沙发"，要在图里框出是哪个。我们 R2R 失败分解 77% 在这。T1 自训接地头 cerr 0.118 已碾压 Qwen(0.50) 和 GDINO(0.230)。
- **场景图（Scene Graph）**：把环境建成"节点=物体+属性+位置"的图，当 RAG 数据库给慢脑查。我们 ConceptGraphs 链已通（185 节点），专留另一篇论文。

### 2.3 评测指标一句话版
- **SR** 成功率（停对没）；**OSR** oracle-SR（走到过附近就算，不问停）；**SPL** 成功率×路径效率；**NE** 终点离目标距离；**ISR** 子任务成功率（LH-VLN）；**CSR** 条件成功率（子任务按序依赖）；**CGT** 完成子任务数。**SR-OSR 缺口=判停问题；SR 低但 OSR 也低=导航本身问题**——这是我们失败分解的基本功。

## §3 对标论文逐个比（全部核实过，出处见行内）

### 3.1 总表

| 对手 | 他们是什么 | 我们 vs 他们 | 现状裁决 |
|---|---|---|---|
| **DualVLN** (InternVLA-N1, ICLR2026) | 双系统：Qwen2.5-VL-7B全量微调(百万样本/64卡)慢脑 + 小DiT快脑；VLN-CE SOTA | 同架构赛道直接对手 | **LH-VLN 我们赢；R2R 他们赢（训练投入差距，追平进行中）** |
| **FantasyVLN** (CVPR2026) | LH-VLN 榜首（训练后 ISR 11.01） | 同一 benchmark | 他们训练 ISR11.01 我们 zero-shot 3.55——差距诚实，但我们 zero-shot 已居公开第二（MGDM2.34/Aux-Think3.16 全被超） |
| **NavDP** (ICRA2026) | 扩散导航策略，IsaacSim 系 SOTA | 扩散快脑对手 | 不同 benchmark（他们没有 VLN/精定位）；真机 hard-case SR 仅 10%（X-NavDP 自爆） |
| **NaVILA** (RSS2025) | 单RGB无图 VLA+RL行走 | 部署形态参照 | 米级指令导航，无精定位无对接——不同承诺 |
| **NoMaD/ViNT** (Berkeley) | 扩散目标导航，要先drive-through建拓扑图 | 部署模式对照 | 他们也要"先走一遍"，我们渐进建图更优 |
| **Qwen-RobotNav** | MLP回归快脑+91.4分灌GT先验 | 反例 | 去掉 GT 先验掉 79.5 分=不可信；我们零 GT 泄漏 |
| **VLingNav** | VLA(MLP动作头)，非扩散 | 机制对照 | 他们自己声明区别于扩散系；不评 VLN-CE/LH-VLN |
| **iComMa/GSVisLoc/iGaussian** (RELOC系) | 3DGS 重定位论文 | RELOC 对照 | 他们全是"一次性定位"benchmark 设定；我们是**闭环周期纠偏**，不撞车且他们的失败实验给我们背书 |

### 3.2 和 DualVLN 的细节对比（最重要的对手）

| 维度 | DualVLN | 我们 |
|---|---|---|
| 架构 | 慢脑VLM+快脑DiT（通用双系统） | 同（这个不是创新点，别 claim） |
| 慢脑 | 7B 全量微调（百万样本，64卡） | VLM 零样本调用 + 场景图 RAG + 四段 confirm |
| 快脑条件 | pixel-goal 帧（图像当目标） | goal_ego 坐标 + status 语义 + NavCmd Φ=(W,γ,vx) + scene_gate |
| **语义可控** | ❌ 无 | ✅ 换条件→轨迹分布变（门值铁证 0.98→0.046） |
| **精定位** | ❌ 无（成功阈 3m 就完事） | ✅ RELOC 5.6cm + DOCK 横向≤0.7cm |
| 里程计依赖 | 用 odometry 做轨迹变换 | 无 odom 照样跑（RELOC 周期纠偏） |
| R2R SR | 58.6-64.3（自报） | 5.3-5.9（zero-shot/微调）→ **追平中** |
| LH-VLN(官方test) | ISR 2.62 / CSR 1.34 / SR 0 | **ISR 3.55 / CSR 2.81 / SR 0.25 全超** |
| 训练投入 | 百万样本×64卡 | 33万样本×1-2卡 |

**为什么 R2R 落后**：0831 调研实锤差距=训练投入（他们百万样本+DAgger+4种相机增广），不是架构。且我们自己送分：旧训练数据朝向恒沿路径→快脑学成"永远直走"（oracle 探针 18/18 全败），0831 稠密+jitter 重训就是修这个。

## §4 我们"必定更好"的条件清单（诚实版）

### 4.1 已经赢的（有数字，可直接写论文）
1. **LHPR-VLN zero-shot**：官方 test n=397，ISR 3.55 vs 2.62(+35%)、CSR 2.81 vs 1.34(翻倍)、CGT 1.42 vs 1.15、SR 0.25:0 —— 同集同 metrics 复算，无水分。（`docs/评测_LH-VLN官方test_T1全量_0830.md`）
2. **精度维度碾压一切 VLN 对手**：RELOC 5.6cm/1.08°、DOCK 横向≤0.7cm、面距 15cm——DualVLN/NaVILA/FantasyVLN 整个赛道成功阈是 1-3m，**他们架构上就没有精定位模块**。
3. **语义可控性**：机制（scene_gate）+ 评测协议都是空白，我们有门值铁证+可控性对比图，协议有 ICML2025 范式背书。

### 4.2 条件成立就赢的（条件在收敛中）
4. **R2R 追平 DualVLN**：条件=训练规模匹配。dense 重训（33万样本，进行中）+ oracle 探针验证转弯恢复后，SR 应显著升。赢不了全部也至少证明"同等投入下架构不劣"。
5. **无 odom 真机鲁棒性**：条件=真机部署完成。所有对手都假设里程计存在，我们 RELOC 周期纠偏专治无 odom——真机评测这条赛道上我们没有对手。
6. **渐进部署**：条件=frontier 模块 P-1 仿真验收。无图即跑→自主建图→热切换，ViNT 要人工 drive-through，DualVLN 永远没有图——我们的部署 story 是唯一的。

### 4.3 诚实弱项（别 over-claim）
- R2R SR 目前 5.3 vs 58.6（追平中，没追上前别声张）
- LH-VLN NE 略逊（锁错实例走更远）
- 回归头真机域差 15.3cm（比纯 GS 差，是速度换的）
- 算力差距是结构性的（1-2卡 vs 64卡），论文叙事要把"低投入"转成卖点不是藏短板

## §6 学习路径（从哪入手）

1. **先跑通一条链**（手感最快）：R2R smoke10（§5 命令），看 jsonl + diag png，把"观测→慢脑→快脑→动作"在脑子里过一遍。
2. **读一个文件**：`our_agent.py` 的 `act_r2r`——它是整个系统的缩影（特征构造→慢脑→快脑→控制→stop），读懂它=读懂全链。
3. **读一份失败分解**：memory 里 0831 的 min_dtg 分解 + oracle 探针实验——学"怎么把玄学失败拆成可定位的层"。
4. **概念补课顺序**：扩散策略（DiffusionDrive 论文）→ VLN-CE/R2R 协议 → render-and-compare 重定位（iComMa）→ ConceptGraphs（场景图）。每篇都有我们的对应模块，学完立刻能在代码里找到实物。
5. **别一次全读**：五层每层一个入口文件就够（§1 图里的粗体），其余用到再查。
