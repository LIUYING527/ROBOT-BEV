# 论文创新点梳理（2026-08-19，与师兄讨论版）

> 配套：`docs/各模块baseline对照_0819.md`（baseline证据）、`docs/调研_VLM-Diffusion_novelty与SOTA_0708.md`（novelty划界）。

## 0. 不能卖的

"VLM慢脑+扩散快脑"通用架构 = DualVLN(ICLR2026) 已做，架构是舞台不是节目。引言必须主动划界。

## 1. 核心创新（脊柱）：语义可控的多模态轨迹分布——提出、实现、并度量

- **多模态**：扩散生成轨迹簇，回归只能 mode averaging（撞墙）。注意限定：普通扩散多样性仅11%，锚点+截断才兑现（DiffusionDrive原文自证）。
- **语义可控**：同一目标位置，换行为条件Φ（巡航/左检视/右检视/暂停）→ 轨迹分布变。DualVLN是"慢脑给像素目标+快脑跟随"，我们是NavCmd(τ+Φ)行为级可控。2026最新三竞品（Qwen-RobotNav/VLingNav/FantasyVLN）此格仍全空（0819核实）。
- **可度量**：探针A~E协议 + 轨迹簇可分性指标，做成小benchmark = 独门指标。
- **机制证据**：scene_gate门控——转向g=0.05关场景/前进g=0.96开场景。可控性从"声称"变"解剖可见"，是论文最漂亮的一张图。

## 2. 三个支撑创新

- **A. RELOC周期纠偏框架**：别家渲染-对比是一次性定位benchmark设定（iNeRF→iComMa→GSplatLoc谱系）；我们是系统级周期纠偏环治"无里程计低成本底盘长程漂移"。iComMa消融（去匹配模块失败率9%→38-40%）为我们双闸门设计背书。增量：双闸门（终值+必须下降，防溅射区假接收）、回归头快路/GS慢路双速。
- **B. 几何真实原则**：生成（3DGS渲染/ArtiFixer）只进皮肤层喂感知；导航/避障/对接几何全来自实测（zed深度+场景图三角化）。反打生成式世界模型路线（幻觉进几何=撞墙）。配套：场景图RAG零手标坐标；VLM只做选择题不出坐标（实测口头方位不可靠）。
- **C. 工业巡检真机全链**：巡航→纠偏→厘米级对准(横向≤0.7cm)→VLM多段确认→15cm贴脸对接。榜单ISR~11%且榜上无扩散方法无巡检场景；精密对接赛道无公认学习类SOTA（0819补调）→不拥挤。

## 3. 分析/经验章节素材（训练侧，单变量迭代都有数据）

1. 条件休眠：稀有条件13%占比被网络无视(输出差0.003m)，3×过采样救活；
2. goal=0自带开关语义，额外模式位冗余（negative result）；
3. BEV时序历史γ^lag衰减（hist_w），官方架构零改动，W=0逐位兼容；
4. GT铁律：真图+真实未来轨迹（渲染图域差+程序扰动19%贴墙两头烂）；
5. v1→v5 loss链：0.44→0.327→0.272 + 每版闭环验收；
6. DFS骨架搜索数据（死胡同回退GT）学会真探索。

## 4. 创新点 ↔ 证据 ↔ 缺口

| 创新点 | 已有证据 | 投稿前缺 |
