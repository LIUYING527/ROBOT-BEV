> 用户判断：**架构没问题，缺的是训练**，所以 benchmark 干不过最好的论文。
> 复盘结论：判断成立。当前四个组件里三个是 zero-shot/规则（VLM 慢脑、bbox 接地、探索策略），
> 只训了快脑和 stop 头——而 FantasyVLN/DualVLN 是**全组件在任务数据上训过**的。
> 关键资产：官方 oracle 轨迹 + 仿真器语义传感器 = **免费的全自动监督**，不用手标一条。

## 阶段计划

### T0 — 接地监督数据生成（今晚，纯机械化）
- **LH-VLN**：回放 batch_1-5 oracle 段（604ep 位姿已在 adapt_lhvln 盘上），每帧开 `semantic_sensor`：
  目标 obj_centers 中心反投影 → 取该像素 semantic_id → mask → **bbox 真值**；
  正例=目标可见帧（bbox+文本"towel in bathroom"），负例=目标不可见帧。
  产出 ~3-4 万条 (image, text, bbox/absent)。
- **R2R**：MP3D 语义同类生成（landmark 文本→MP3D 类别映射部分覆盖，后补）。
- ✅ 已验证：semantic_sensor (512×512 uint32 instance id) + scene 420 对象 + obj_centers.json 全通。

### T1 — 接地头（核心，主攻 77%）
- 基线对照先试 **GroundingDINO/OWLv2 zero-shot**（官方开源检测器，用户规则=先用现成）；
  下载受墙限制走 hf-mirror，拿不到就跳过。
- 自训（主路线）：resnet34(暖启) + 文本嵌入（BERT 词向量，目标类名+房间）→ bbox 回归+存在性分类，
  场景 hold-out 验证。与 robo2vlm bbox 同集对比（定位误差中位数）。
- 集成：接地头出 bbox → 现有几何反投影 → target_world；**加多视实例记忆**（同一实例多帧投票，
  防单帧幻觉锁错——这是架构内的小补丁，不是改架构）。

### T2 — crop 确认头（补 LH-VLN stop 头之败）
- 失败复盘：整图判"到没到"对小物体不可学（AUC0.65）。改：**接地头 bbox 裁剪 → 裁剪图+文本 → 到点二分类**
  （目标在裁剪里被放大，任务从"找+判"变"只判"）。数据=T0 同一批（crop 在线生成）。

### T3 — 快脑扩容（机械扩产）
- 数据 2000→6000ep（s4/s5 回放中）重训 goalnav_r2rft；有卡后上 DAgger（自滚+oracle 纠偏）。

### T4/T5（后排，本周不做）
- T4 慢脑解析蒸馏（VLM 当 teacher 标 train 集 → 小 seq 模型）；T5 指令条件 e2e IL（仅作消融上限）。

## 0829 凌晨 T1 结果与转向（诚实负结果）

**T1 接地头 val(batch_6) 端到端对照**: T1v3(头+vantage三修) ISR 3.7/NE12.90/153步 vs P0(robo2vlm) ISR 3.7/NE11.76/42步——**打平**。
- 头的离线优势(R0.60/cerr0.118/5ms vs Qwen R0.02/cerr0.50/2.3s)**没有转化成端到端收益**；
- 三修记录: vantage探索(扫12步→前进2.5m, 虚拟点到达不停靠`_tw_is_landmark`门控)/近距absent信头不追问VLM(17min→5min每ep)/子任务切换清缓存。
- **结论: 接地"够用"后, 约束移到探索策略**——head/VLM 都是类级检测(找"a table"非"the table in dining room"), 锁错实例依旧; 且 77% NE>5m 失败里目标常在其他房间, 盲目 vantage(局部前进)不是房屋级搜索(过厅找门进屋)。
- **转向 T5(指令条件 e2e IL) 从消融升级为主线候选**: oracle 轨迹教的正是"怎么搜"(出房→走廊→进对房间), R2R 快脑微调 OSR 翻倍已证此路; LH-VLN 侧做子任务条件(target+room)的探索策略训练。
- T1 头保留集成(与 VLM 打平但快400×+不依赖外部服务器=运维鲁棒性), 不作为提分手段宣称。
- R2R topup2(显式 `env.episodes=[ep]` 对齐修复后)补齐 300ep 中; ⚠Qwen 当 R2R 慢脑显著弱于 robo2vlm(SR 0/61 vs 14/239), robo2vlm 恢复后 R2R 需重跑。
