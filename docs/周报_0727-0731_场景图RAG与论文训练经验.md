## 1. 场景图 RAG：算法目标、框架与数据流（0728–0729 建图全链通）

### 1.1 算法目标

把巡检任务的"**目标在哪（WHERE）**"从手搓几何（VLM bbox 伺服/单像素反投影/手标坐标——0722 起三度被否的旧拐杖）换成**可查询的开放词表 3D 语义地图**：自然语言查询 → 场景图节点 → 3D 坐标/正面朝向/外观卡片，任务层（lab_mission）只消费节点参数，环里零 bbox。

### 1.2 框架

```
离线建图(一次性, ConceptGraphs)                在线查询(每次任务)
510帧 posed RGB-D ──→ 185节点场景图 ──→ RAG检索: 文本查询→top-k节点
                                            ↓
                              任务层: 节点坐标→站位/朝向(纯几何解析)
                              慢脑VLM: crops/实时渲染→判断式confirm
```

### 1.3 输入 / 中间状态 / 输出

| 阶段 | 内容 |
|---|---|
| **输入** | 110744s2 采集：**510 帧 posed RGB-D**（COLMAP 位姿 + ZED RGB + 逐帧度量深度），stride2 → 255 帧进检测 |
| **中间状态** | ① 每帧 RAM 开放词表打标 → Grounded-SAM 检测+分割 → **959 个物体实例**（mask/xyxy/conf/pixel_area）；② 深度反投影+位姿融合成实例点簇；③ CLIP 特征+空间重叠合并 → **185 个节点**（每节点：3D 点簇、~20 次检测记录、best-view crops 外观卡片、RAM 多数票 tag、clip_ft） |
| **输出** | **场景图（185 节点）+ RAG 查询接口**：文本查询 → 相似度排序 → top-k 节点的 3D 坐标/朝向/crops。冒烟实测：microscope 0.50m 命中 |

## 4. Qwen-RobotNav 论文精读与训练经验迁移（0731 下午）

论文 PDF（37 页）已精读，核实版分析见 memory `qwen-robotnav-paper-verified-0731`
（纠正了外部讨论稿多处编造：任务模式仅 4 种无 DRIVE、γ∈[1,3]、B∈[2048,4096]、
NAVSIM 91.4 PDMS 系灌前 3 帧 GT 轨迹、输出为 8 航点 MLP 回归非离散动作）。

本周**已完成**的改动共 6 项，各自的意义如下。

### ① 数据再平衡：直线只留 45%、转向全留、决策点×2
`goalnav/pipeline/train_goalnav_gate_v2.py`，按 GT 末点偏航角分类（<10° 直线留 45%，≥35° 决策点复制×2），621→656 样本。
**意义**：GT 的动作分布就是模型学到的行为先验。巡航样本占绝对多数时，模型学到的是"大概率直走"的惰性先验，转向/停止这些**关键决策**被淹没——论文§4.1.2 的规则（前进 45%/转向停止全留）把监督信号的信噪比摆正，花的只是筛样本的成本。

### ② 条件 dropout：同轨迹多先验变体
同 script，直线样本 30% 追加"目标点置零"变体（同观测同 GT，仅 status 目标=0；直线时走廊跟随≈目标跟随，监督不冲突）。
**意义**：防止模型把全部因果挂在目标点条件上。同一观测下"有目标→跟目标"和"没目标→跟场景"都见过，条件注入学到的是**真因果而非相关**；条件缺失/降级时模型退回场景驱动而不是抓瞎。也与 gate 机制解耦防绑架。

### ③ 条件连续化 + 每样本随机化
`scripts/gen_nav_dataset_lab_v3.py`：起点 xy±0.25m/yaw±0.4rad 连续抖动（替代固定三档 dyaw），目标方位 ±100°、距离 [1.0,6.0]m 连续采样。
**意义**：这是论文"训练时配置随机化"的核心思想落地——**离散档位教出"背模式"，连续随机参数教出"按参数调行为"**，模型因此能泛化到训练中没见过的参数组合。是我们的条件从"9 类分类标签"走向"参数化导航接口"的第一步。

### ④ 减速段 GT：前疏后密航点
同 v3 生成器，目标在 1.6m 视窗内时 GT 航点按二次分布（实测末/首段间距比 0.08）。
**意义**：匀速 GT 教出的是"冲过目标"，减速间距教的是"到站前平滑收速"——这是巡检**到站对准**动作的前提，也让 v3 闭环轨迹更长更稳（401 帧 vs v2 335 帧，接近目标不再急刹）。

### ⑤ 速度随机化 vx
v3 每样本 vx~U(0.3,0.8)、近目标 U(0.15,0.35)，写入 status[4]（原全数据集固定 0.4）。
**意义**：论文的 speed augmentation——同一轨迹在多种速度 regime 下监督，模型对执行速度鲁棒，运行时调 `--speed` 不再是分布外输入。

### ⑥ 分域归一化统计（备用）
`outputs/traj_norm_scales.json`：lab_v3 1.56m / lab_v2 2.87m / corridor 3.49m / NAVSIM 32m。
**意义**：各域轨迹尺度差 20 倍，联合训练时 loss 量纲混杂会互相压制；按域 99 分位归一化到 [-1,1]、推理反归一化，是论文多任务混训不打架的基础手段。下次跨域联合训练时启用。

## 5. 经验沉淀（本周买到的教训）

1. **改几何必须想清哪份文件进哪条渲染路径**：world ply（占据）与 pre-align ply（画面）要同步扶平。
2. **厚板 SVD 法线/大裁 PCA 不可作微调依据**；视觉零交叉（LSD 线倾角 vs yaw）才是"正"的直接度量。
3. **窄基线三角化残差小≠准**；检测弧有偏则统计继承斜视。
4. **产物版本化**：本周 8 版任务视频全部保留可回溯（geo0730/geo0731/perp/lvl/lab_v2...）。
