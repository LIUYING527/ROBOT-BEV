世界坐标均为 0.70× 真实尺度（0811尺度根因，补丁标注）。

## 左栏 FPV（机器人看到的渲染画面）

| 英文 | 中文 | 怎么读 |
|---|---|---|
| `[SLOW-VLM] PHASE ->LEG` | 慢脑（VLM）当前阶段 -> 目标腿 | 绿色行，慢脑在干什么 |
| `[FAST-DD] ...` | 快脑（DiffusionDrive）输出摘要 | 蓝色行，当前速度/模式 |
| `VLM: IRON CABINET? -> YES(primary)` | VLM确认结果 | primary=初判通过；review(n/3)=初判no、关键帧复核n/3翻案；NOT-CONFIRMED=如实判否 |
| 黄色十字 | 画面中心 | 对正目标时应压住绿X |
| 绿色X | 目标3D点投影 | 场景图节点投到画面里应在的位置 |
| 青色线段 | 正脸线 | 过目标⊥front方向的水平线；正对时它水平且过中心 |
| 白色虚线 | 人工水平基准 | 判断画面歪不歪用的参考线 |
| `front=167deg yaw_err=+0.0deg` | 目标正面角 / 当前朝向误差 | yaw_err越接近0越正对 |

### 下方 8段管线（绿色=正在执行，白=已完成，灰=未轮到）
| 行 | 英文示例 | 中文含义 |
|---|---|---|
| [1]WHERE graph | `tau=iron_cabinet@(-0.58,-3.56) front=167.0d -> standoff(0.30,-3.76)` | 去哪：场景图给出的目标节点坐标、正面角、站位点 |
| [2]PLAN A* | `A* 13pts len3.7m` | 怎么去：A*在占据栅格上规划的路径，13个点3.7米 |
| [3]RELOC | `drift 0.08m/1d -> residual 0.3cm/0.1d loss0.07->0.02 ACCEPT` | 精定位：漂移多少→纠正后残差多少；loss是渲染深度与观测深度的匹配误差，≤0.08采纳(ACCEPT)，否则拒收(REJECT) |
| [4]FAST-DD | `Phi(W2,g0.7,vx0.5) -> v=0.12,w=+0.00 d_goal=0.2m he=-12d` | 快脑：Φ参数包（W=历史帧数，g=历史衰减γ，vx=速度档）→输出速度v/转向w；d_goal=距终点；he=朝向差 |
| [5]ALIGN | `it2: lat-off 0.00m, bearing-front -0.2d` | 到站对准：第几轮迭代、横向偏轴距离、与正面的方位差（收到1.5°内） |
| [6]SLOW-VLM | `Scene='Microwave' Action=YES` / `keyframe review f246: YES` / `VERDICT ...` | 慢脑四段推理链：Scene=VLM描述画面（⚠只参考，不信描述）；Action=严格yes/no；初判no→回查接近过程3个证据帧复核；VERDICT=最终判定 |
| [7]DOCK | `servo it4: face 47cm [GEO<ED54]` / `center it2: seam_x=272 off -13.3cm` / `blind-crawl 21cm -> 15cm` | 贴脸对接：面距伺服（[EDp10]=渲染深度p10读数，[GEO<ED]=ED过读取几何下限，[KEEP]=跳涨拒信）→居中（seam=门缝LSD/centroid=簇质心，off=横向偏差）→盲爬（近场深度不可信，按几何走最后一段） |
| [8]METRIC | `lat1.0cm berr0.7d front0.9d dist0.78m (true-pose)` | 验收（全部用真位姿测）：横向偏轴/方位差/正面差/距目标 |
